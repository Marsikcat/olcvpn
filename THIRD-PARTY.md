# Сторонние компоненты в этой сборке

## bin/olcrtc-fork.exe

Ядро туннеля. Собрано из [Oleglog/OlConnect_manager](https://github.com/Oleglog/OlConnect_manager)
(бывший Olcrtc_manager), тег `server-v2.3.5`, коммит `389dea9a69d7` (21 сентября 2026),
**с одной правкой** — `patches/olcrtc-reorder-hold.patch` в этом репозитории.

Без неё ядро не работает через Телемост с начала октября: буфер переупорядочивания
RTP ждал пропавший пакет, пока не накопится 256 следующих, а Телемост стал
оставлять в нумерации дыры, которые никогда не заполняются. Каждая дыра
останавливала поток примерно на 25 секунд — дольше, чем ждут приветствие и
проверку связи. Правка ограничивает ожидание четырьмя пакетами; потерянное
восстанавливает KCP. Та же правка нужна и на сервере.

Именно этот форк — не upstream [openlibrecommunity/olcrtc](https://github.com/openlibrecommunity/olcrtc) —
стоит на серверах, поэтому только он и договаривается с ними по проводу.
Сборки из upstream входят в комнату, видят видеопоток и виснут на
`wait for peer` или `read welcome: timeout`.

Лицензия: WTFPL.

## bin/sing-box.exe

[SagerNet/sing-box](https://github.com/SagerNet/sing-box) 1.13.11,
ревизия `553cfa1f9f99`, сборка без изменений. Нужен для режима «Весь
трафик» — поднимает TUN-интерфейс и заворачивает в него систему — и для
VK TURN, где он же поднимает WireGuard.

Лицензия: GPL-3.0. Исходный код доступен в репозитории проекта по ссылке выше.
Без него не работают режим TUN и VK TURN; подключения через Телемост в режиме
«Только прокси» работают и так.

## bin/vkturn-client.exe

Клиент [vk-turn-proxy](https://github.com/cacggghp/vk-turn-proxy) — нужен
только для серверов VK TURN. Собран из
[PR #183](https://github.com/cacggghp/vk-turn-proxy/pull/183)
([NikKuz99/vk-turn-proxy](https://github.com/NikKuz99/vk-turn-proxy), ветка
`fix/captcha-tls-auto-solver`, коммит `b8c4ffab11f2`) **с двумя правками** из
папки `patches/` этого репозитория: `vkturn-no-browser.patch` — при
`VKTURN_NO_BROWSER=1` клиент не открывает внешний браузер для капчи, её
показывает окно olcvpn; `vkturn-call-access.patch` — доступ к звонку,
полученный после капчи, переиспользуется для новых учёток TURN и с флагом
`-access-pipe` передаётся olcvpn, так что капча нужна раз за запуск.

PR нужен потому, что релиз v1.8.3 не понимает новый формат капчи VK
(октябрь 2026) и не получает доступ к звонку.

Лицензия: GPL-3.0. Полный исходный код этой сборки — коммит по ссылке выше
плюс патчи из этого репозитория; как собрать — в README, раздел «VK TURN».
Текст лицензии лежит рядом: `bin/vkturn-client.LICENSE`. Если VK TURN не
нужен, файл можно удалить — остальное работает без него.
